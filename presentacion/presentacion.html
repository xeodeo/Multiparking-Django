02 — Necesidad

El
Problema

Los parqueaderos multinivel en Colombia manejan su operación con métodos manuales.

  • Control manual en papel o Excel, sin visibilidad en tiempo real
  • Cobros calculados a mano — errores y demoras en la salida
  • Sin historial de vehículos ni trazabilidad de incidentes
  • Sin posibilidad de reservar un espacio antes de llegar
  • Resultado: filas, pérdida de ingresos y mala experiencia
02 / 12

03 — Solución

¿Qué es
MultiParking?

Aplicación web que digitaliza completamente la operación de un parqueadero multinivel.

multiparking-django.onrender.com
  • Control de espacios en tiempo real
  • 3 roles: Administrador · Vigilante · Cliente
  • Cálculo automático de cobro al salir
  • Reservas online desde el celular
  • Reportes exportables en PDF y Excel

04 — Arquitectura funcional

Tres perfiles, tres experiencias

Administrador

  • Dashboard con gráficos en tiempo real
  • Gestiona pisos, espacios y tarifas
  • Exporta reportes PDF / Excel
  • Gestiona usuarios y cupones

Vigilante

  • Registra ingreso de vehículos
  • Calcula cobro al registrar salida
  • Confirma pagos en efectivo
  • Ve ocupación en tiempo real

Cliente

  • Reserva espacios con fecha y hora
  • Gestiona sus vehículos
  • Acumula stickers de fidelidad
  • Salida rápida con código QR

05 — Patrón de diseño

MVT — Model · View · Template

M
Model
Define datos, validaciones y reglas de negocio. ORM Django + validators + propiedades calculadas.
V
View
Class-Based Views con mixins de autorización por rol. Lógica de negocio sin Django Forms.
T
Template
Server-Side Rendering con Tailwind CSS. AJAX puntual para operaciones sin recarga.
Middleware chain de seguridad 10 apps independientes Singleton en Fidelidad

10 — Compilador o intérprete

Python es Interpretado

  • El intérprete CPython ejecuta el código línea a línea — sin compilar a binario
  • Gunicorn recibe la petición HTTP y la pasa a Django
  • Django (Python) procesa la vista y consulta a PostgreSQL
  • El template se renderiza y se devuelve HTML al navegador
# Django procesa cada request así: def calcular_cobro(minutos, tarifa): horas = minutos / 60 monto = horas * tarifa.precioHora # Redondear a 100 COP más cercano return ceil(monto / 100) * 100 # Sin compilación → despliegue inmediato # con build.sh en Render.com
